# Farmington House of Pizza (Farmington, NH) - 9/10
- Website: https://www.farmingtonhouseofpizza.com/
- Location: 485 Main St, Farmington, NH 03835
- Phone: (603) 755-9001
- Rating: 9/10
## Problems found
- Old Community Communications template site that looks quickly made; the homepage is almost entirely images (logo banner, background photo and a "welcome" graphic) with the Order Online and Call Us buttons drawn into the banner image as clickable image-map hotspots
- Viewport tag uses old, invalid syntax with user-scalable=0, which blocks pinch zoom on phones
- The plain http:// version of the site returns a server error (HTTP 500) instead of redirecting to https
- The linked "Download Menu" PDF was last updated in May 2016, while the menu page is a long plain text price table
- Homepage still promotes an old eDiningExpress phone app (Google Play and iOS badges) alongside a separate OrderCounter online ordering page
## Why it's a good opportunity
A small family shop with a dated, image-only homepage and a text-table menu, so the owner will see clear value in an upgrade: a parallax hero, real readable homepage content, and a cleaner, more visual menu built from their existing menu.
## Design notes
Use the shop's existing content only. Never use AI-generated food images. Benchmark: https://www.dominos.com/
