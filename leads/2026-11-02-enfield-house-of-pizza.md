# Enfield House of Pizza (Enfield, NH) - 8/10
- Website: https://www.enfieldhouseofpizza.com/
- Location: 554 US Route 4, Enfield, NH 03748
- Phone: 603-632-5800 or 603-632-7211
- Rating: 8/10
## Problems found
- Older Wix site whose pages still use default auto-generated URLs (/blank, /blank-1, /blank-2, /menus-1, /menus-2, /menus-3, /fresh-salads-1, /locations-hours-1)
- Header "ORDER ONLINE" button links to http://Togoorder.com/web/5102, which returned an HTTP 500 error on the http link (only the https version works)
- Menu is split across about seven separate plain-text price-list pages instead of one easy menu
- Specials page still promotes "THE OCTOBER FEATURE PIZZA" in November
- Job application is a PDF to download, fill out by hand and bring in person; no online form
- Typo-style glitches in the header hours ("M onday: Closed", "Tuesday - SUnday")
- Homepage is a long asterisk bullet list of features with little visual structure
## Why it's a good opportunity
A family shop serving the Upper Valley since 1987 with a dated, quickly made Wix site, a paper job form, a shaky ordering link and a scattered text-only menu, so a modern one-page menu and ordering flow is a clear win.
## Design notes
Use the shop's existing content only. Never use AI-generated food images. Benchmark: https://www.dominos.com/
